# MPV 播放器内核

按需安装的 MPV 播放器内核。默认播放器仍为系统 Media3。

- 插件 ID：`com.limi.player.mpv`
- 作者：ABU Launcher / media-kit contributors
- 项目主页：https://github.com/Mashiro000/ABU-plugins
- 源码：https://github.com/jarnedemeulemeester/libmpv-android
